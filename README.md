# FurniZone 🏠

A modern, responsive furniture store website built with HTML, CSS, and JavaScript.

🔗 **Live Demo:** [https://gokul05102003.github.io/FurniZone/](https://gokul05102003.github.io/FurniZone/)

---

## ✨ Features

- Clean, modern furniture showcase and storefront UI
- Interactive elements for browsing collections
- Fully responsive design for desktop and mobile devices
- Lightweight vanilla frontend with no external dependencies

## 🛠️ Built With

- **HTML5** – Page structure and semantic markup (`index.html`)
- **CSS3** – Styling and responsive layout (`styles.css`)
- **JavaScript** – Interactive features (`main.js`)
